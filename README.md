# -SECURBTP-001
## Mod `context-bar`

Barre de progression verte sous le prompt de Claude Code : part du contexte consommée, total cumulé de tokens et coût de la session en €.

Installation (terminal Claude Code, une fois, portée « user ») :

```
/plugin install context-bar --marketplace adace30/-SECURBTP-001
```

Le taux EUR/USD (0,86 par défaut) se règle dans la configuration du plugin.
